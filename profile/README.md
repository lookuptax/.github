# LookupTax

**Tax identity infrastructure for the global economy.**

LookupTax provides APIs and developer tools for validating business tax identities and accessing tax-related business data across countries.

We turn fragmented government registries, tax systems, and compliance infrastructure into **simple, developer-friendly APIs**.

## What we build

### 🧾 Tax ID Validation

Validate business tax identifiers across 100+ countries.

* VAT numbers
* GST numbers
* EIN / FEIN
* ABN / NZBN
* National business identifiers
* Country-specific tax registrations

```text
One API → Global tax ID validation
```

### 🌍 Global Tax Infrastructure

We build the infrastructure required to answer questions like:

* Is this tax ID valid?
* Which country issued it?
* What type of tax identifier is it?
* What business is associated with it?
* Is it registered for a particular tax system?
* Can the identifier be verified through a domestic authority?

### 🛠 Developer Tools

Our ecosystem includes:

* Validation tools

## Why LookupTax?

Tax identity data is surprisingly fragmented.

Every country has its own identifiers, formats, registries, APIs, authentication mechanisms, availability constraints, and rules.

LookupTax abstracts that complexity behind developer-friendly infrastructure.

**Instead of integrating dozens of government systems, integrate one API.**

## Developer ecosystem

LookupTax is built API-first, with official SDKs and libraries for the languages developers use to build global commerce applications.

**Official SDKs**

* [Python](https://github.com/lookuptax/lookuptax-sdk-python)
* [JavaScript / TypeScript](https://github.com/lookuptax/lookuptax-sdk-javascript)
* [Go](https://github.com/lookuptax/lookuptax-sdk-go)
* [.NET](https://github.com/lookuptax/lookuptax-sdk-dotnet)
* [Java](https://github.com/lookuptax/lookuptax-sdk-java)

The SDKs provide a native interface to LookupTax's tax ID validation APIs, including synchronous validation, batch validation, registry-specific routing, and structured validation outcomes.

**Packages**

* [PyPI — `lookuptax`](https://pypi.org/project/lookuptax/)
* [npmjs — `lookuptax`](https://www.npmjs.com/package/@lookuptax/sdk)

Our goal is simple: **make global tax infrastructure feel like a normal developer API.**
